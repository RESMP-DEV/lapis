Three child modules compose a layered session service: `transport_protocols` exposes the binary wire format, frame parser, and pacing helpers; `posix_platform` provides the OS-specific PTY process group, Unix-domain socket endpoint, and RAII fd wrappers; `session_core` pulls them together into a `QCoreApplication`-driven service that owns the terminal emulator, history store, attention journal/audit, checkpointing, and lifecycle hooks. Cross-child wiring is performed by `src/session_service.cpp`, which constructs the platform endpoint and protocol layer behind the shared `include/lapis/session/` headers (`terminal.hpp`, `attention.hpp`, `observation_phase.hpp`) that the core exposes to callers. Tests under `tests/` mirror the three-layer split (protocol, platform, core) so each layer can be exercised independently.
