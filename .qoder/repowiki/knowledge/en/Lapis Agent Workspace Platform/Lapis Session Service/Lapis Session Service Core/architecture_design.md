The `session_service.cpp` entry point owns a Qt event loop and composes three child subsystems around it:
- The POSIX platform layer (`platform/posix/*`) creates PTY-backed `PtyProcess` instances and exposes them via `LocalEndpoint` (Unix-domain server + socket).
- The transport layer (`transport/*`) serializes snapshot frames and control messages over those endpoints using the local protocol and an attention-specific wire format.
- The attention subsystem (`attention_journal.*`, `agent_checkpoint.*`, `history_store.*`, `history_worker.*`) persists request state to an append-only CRC-32 journal and drives background history work.
All three are plugged in from `session_service.cpp`, which also hosts the `Terminal` class (defined in `include/lapis/session/terminal.hpp`) — an in-process screen buffer with row-major cells, grapheme storage, hyperlink spans, and a strict per-turn reply drain. Cross-child communication is strictly message-based: the transport decodes wire bytes into snapshot structs, the terminal mutates its owned `TerminalSnapshot`, and the attention journal records state transitions without touching I/O or threads itself. Platform isolation is enforced by the `platform/posix/` boundary; only that directory calls POSIX APIs (PTY, process groups, `unique_fd`).
