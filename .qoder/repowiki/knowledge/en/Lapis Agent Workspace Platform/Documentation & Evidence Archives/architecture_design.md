Two parallel, read-only archives under this scope:
- `docs/` — human-authored Markdown covering user-facing topics (`usage.md`, `install.md`, `config.md`, `keys.md`, `phone.md`, `ultratab.md`, `workspace.md`, `suggestions.md`, `status.md`) and developer-facing topics (`agents.md`, `architecture.md`, `build.md`), plus a dated design spec under `superpowers/specs/`.
- `evidence/` — JSON (and one `.md`, one `.txt`) files produced by automated review/probe/triage agents. Naming conventions encode provenance: `<topic>-review.json`, `<topic>-repair*.json`, `<topic>-followup.json`, `<topic>-triage.json`, `prNN-*.json` for pull-request reviews, `r1/r2/...` for release candidates, `android-milestone-*.json` for device/server milestones, and timestamped filenames (e.g. `architecture-buildout-triage-20261017.json`) for recurring runs. Files are consumed as inputs to downstream automation rather than compiled; they have no runtime dependency on application code.
