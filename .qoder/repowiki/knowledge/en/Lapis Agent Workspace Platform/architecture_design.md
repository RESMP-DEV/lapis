The root `CMakeLists.txt` is the single build entry point: it enforces macOS/Linux + C++20, includes shared options from `cmake/ProjectOptions.cmake`, and wires children via feature flags (`LAPIS_BUILD_SESSION`, `LAPIS_BUILD_DESKTOP`, `LAPIS_BUILD_ULTRATAB`, `LAPIS_BUILD_SUPERVISOR_*`). The `lapis_session_service` target is the core process; `adapters/codex` and `adapters/claude` link into it as plugins, while `services/session` provides the PTY/IPC layer they share. Desktop (`apps/desktop`) and overlay (`apps/ultratab`) depend on the session service; the `supervisor` runtime optionally wraps it. Cross-language tooling (Python scripts under `scripts/`, `justfile` recipes, `.clang-*`, `ruff.toml`, `.editorconfig`, `Brewfile`) is coordinated by `scripts/lapis.py` so every child shares one quality/build surface. Android and iOS children are built outside this CMake tree but communicate with the same local Unix-domain socket protocol exposed by the session/supervisor services.
