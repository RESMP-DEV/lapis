- Pluggable subsystems are exposed as abstract base classes with deleted copy/move constructors and protected constructors (e.g. `StateCodec`, `StateStorage`, `ChildLauncher`, `MonotonicClock`, `IdentityProvider`), with concrete implementations named `<Name> final`.
- Public structs use `operator==` defaulted via `= default` to enable equality comparison across `DesiredSession`, `SupervisorState`, `ControlRequest`, etc., and validation helpers (`valid_hex`, `valid_state`, `valid_desired_session`, `valid_desired_session_launch`) live alongside the schema.
- Secrets and identifiers are treated as lowercase hex strings validated through `constant_time_equal` and length-checked against compile-time constants such as `epoch_hex_bytes`, `identity_hex_bytes`, `spawn_token_hex_bytes`.
- External I/O and timing are injected through shared pointers to interfaces (`ChildLauncher`, `MonotonicClock`, `IdentityProvider`, `StateStorage`) so production code and tests share the same `SupervisorRuntime` constructor.
- Binary entry points initialize a `QCoreApplication`, parse arguments with `QCommandLineParser`, and propagate errors by throwing `std::runtime_error`; fatal construction failures in the daemon are caught in a `noexcept` shutdown path.
