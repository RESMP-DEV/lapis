Full runtime is only compiled when `LAPIS_BUILD_SUPERVISOR_RUNTIME` is set; the state-only target can be built independently. Tests are registered under names `supervisor-state`, `supervisor-runtime`, `supervisor-session-service`, `supervisor-daemon`, and `supervisor-client` with explicit timeouts (10–45s). The daemon and test binaries require `LAPIS_SUPERVISOR_SESSION_SERVICE` to point at the built `lapis_session_service` target.
