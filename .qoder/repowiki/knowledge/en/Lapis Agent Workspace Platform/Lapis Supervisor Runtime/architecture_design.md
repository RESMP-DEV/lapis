The module is split into two CMake targets with a strict dependency direction.

- `lapis_supervisor_state` (state-only build): pure C++ layer built from `src/state.cpp`, `src/json_state_codec.cpp`, `src/posix_state_storage.cpp`. It defines the persistence schema (`SupervisorState`, `DesiredSession`, `ControlRequest`) in `include/lapis/supervisor/state.hpp`, plus three pluggable abstractions: `StateCodec` / `JsonStateCodec` for wire format, `StateStorage` / `PosixStateStorage` / `MemoryStateStorage` for disk vs. in-memory, and `IdentityProvider` for epoch/session-id/spawn-token generation. `SupervisorRegistry` is the single-threaded authoritative owner that serializes transitions on top of storage; failed commits poison it so later requests are rejected rather than guessing stale disk contents.
- `lapis_supervisor_runtime` (full build, gated by `LAPIS_BUILD_SUPERVISOR_RUNTIME`): adds process lifecycle via `ChildLauncher` / `OwnershipChildLauncher` / `SessionServiceLauncher`, a monotonic clock abstraction, and `SupervisorRuntime`, which owns restart admission windows (`max_restarts_per_window`, `restart_window_ns`) and convergence state (`Convergence`). It depends on the state target plus `lapis_session_platform` and `lapis_local_protocol` for IPC.
- Entry points: `daemon.cpp` builds `lapis_supervisor_daemon` — a Qt process that parses `--state-directory` and `--control-endpoint`, wires `RandomIdentity`, `JsonStateCodec`, and `PosixStateStorage` into a registry, then launches `SupervisorRuntime` with a `SessionServiceLauncher`. `cli.cpp` builds the `lapis` binary (renamed from `lapis_supervisor`) used as a control client; `client.cpp` and `control_server.cpp` implement the JSON-over-local-socket protocol.
- The runtime's only child ownership seam is the `ChildLauncher` interface, letting tests inject fixtures while production uses `SessionServiceLauncher` to spawn the actual session-service executable. The build also reuses `lapis_session_platform` (a static library of POSIX FD helpers) so the state-only build stays free of Ghostty dependencies.
