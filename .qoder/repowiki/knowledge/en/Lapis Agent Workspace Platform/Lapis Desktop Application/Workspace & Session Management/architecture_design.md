Four cooperating QObject subclasses form a layered model:
- `SessionPreview` (workspace.hpp/.cpp) is the per-agent state object exposed to QML via Q_PROPERTY/Q_INVOKABLE; it owns snapshot decoding, history scrubbing, attention handling, and delegates transport to `LiveConnection`.
- `LiveConnection` (live_connection.hpp/.cpp) wraps a `QLocalSocket` to the service process, implements the session wire protocol handshake, snapshot/history framing, resize coalescing, paste transactions, and retry/backoff with `max_attempts=30`.
- `WorkspaceControl` (workspace_control.hpp/.cpp) listens on a Unix domain socket (`workspace-control.sock`) under the registry folder and dispatches JSON-line requests (harnesses, createAgent, category, agent, terminal, settings, handover) from sibling lapis processes (e.g. phone gateway) into Workspace operations.
- `OpenRequests` (open_request.hpp/.cpp) watches a small JSON request file written by Ultra Tab and invokes an `open` callback for each fresh request older than `max_age_ms=10s`, decoupling windowless host bootstrapping from UI.
Dependency direction: WorkspaceControl and OpenRequests depend on Workspace/SessionPreview; LiveConnection depends only on SessionPreview and the session wire protocol — never the reverse. Transport abstractions (`transport/local_protocol.hpp`, `transport/attention_protocol.hpp`) and session models (`lapis/session/terminal.hpp`, `launch_spec.hpp`) are imported but not modified here.
