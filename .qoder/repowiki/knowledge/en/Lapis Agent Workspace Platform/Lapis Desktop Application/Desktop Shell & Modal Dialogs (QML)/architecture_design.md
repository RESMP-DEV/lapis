Single-level QML package under `apps/desktop/qml/` with one top-level entry point and several sibling dialog components:
- `Main.qml` is the `ApplicationWindow` root that owns window state, theme/keymap resolution, keyboard shortcut dispatch (`bindings`, `fallbackSequences`), input blocking via `inputBlocked` / `interactionArmed`, and composes child views. It imports the C++ extension module `Lapis 1.0` (for workspace, terminal, preview, keymap) and exposes shared computed properties (colors, fonts, density/rail/tab sizing) consumed by every dialog.
- Each other file is an independent `Dialog` component with a narrow contract: a few `required property var engine|themeModel|...` inputs, a single action signal (`requested`, `chosen`, `themeChosen`, ...), and local list/search state (`results`, `pending*`). They are shown/hidden by the parent rather than navigating between them.
- `AgentMark.qml` is a reusable `Item` drawing harness logos via embedded SVG paths in `QtQuick.Shapes.PathSvg`, keyed by `harnessId` — used as a visual badge, not a navigation target.
- Dependency direction is one-way: dialogs depend on `Main.qml`'s exported theme/font properties and on the injected `engine` object; nothing in the dialog set imports each other, keeping the modal tree flat.
