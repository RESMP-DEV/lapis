The app is split into a Qt GUI layer (QML under `qml/`, C++ shell under `src/`) sitting on top of domain services: workspace/session lifecycle (`workspace*`, `live_connection`), agent state publishing + Cmd+K search (`agent_state`, `agent_search`), conversation indexing + terminal history strip (`conversation_index`, `history_strip`, `cell_shapes`), usage/limits/tool-status polling, account plan selection and sign-in flow, and interaction logging/UI capture. The C++ shell (`main.cpp`, `gui_state`, `desktop_actions`) instantiates these services, exposes them to QML via `QQmlContext` properties, and bridges attention/alerts between native macOS notifications and the QML modal stack. Platform-specific behavior (Sparkle updates, login items, chimes, reset journal, system preferences) is isolated in `src/platform/` with `.mm` implementations behind cross-platform headers. Generated C++ headers (`*_script.hpp.in`, `count_tokens.hpp.in`, `limit_resets_script.hpp.in`, `remote_hook_relay.hpp.in`) are produced by Python scripts at build time from the sibling `*.py` sources, so the generated files are the contract consumed by both C++ and tests. Tests mirror the src tree and share fixtures like `wire_fixture.hpp`.
