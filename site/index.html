Built for running many agents at once

Keep a whole team of agents moving without losing track of which one is waiting on you.

One stage, every agent in view

The selected agent gets a full GPU-drawn terminal. Every other agent in the category shows its latest lines in the strip underneath, four times a second.

Knows when an agent needs you

A card pulses when its agent finishes a turn or asks for approval, and the Dock badge counts them. New requests never move your keyboard focus while you type.

Agents outlive the window

Each agent runs in its own session process. Close or restart lapis and you reattach to the same running agents, history included.

Your plans at a glance

See what is left of each signed-in plan, green when there is plenty and red when it is nearly gone, on this Mac and on the machines you add.

Keyboard first

Command-T starts an agent, Command-K finds one, and every binding, theme and default lives in one lapis.json that applies as soon as it changes.

Categories for your work

Group agents by project or task. Each category keeps its own order and remembers which agent you were watching.

Uses the agents you already have

lapis starts the command-line agents installed on your Mac, signed in as you, with the model and approval mode you pick. It holds no keys and needs no account.

Install

lapis is a signed Mac app for Apple silicon.

  1. DownloadGet lapis-macos-arm64.dmg from the latest release.
  2. Drag to ApplicationsOpen the disk image and drag lapis into your Applications folder.
  3. Start an agentOpen lapis and press Command-T. Agents get the same PATH and settings as your terminal. Settings live in ~/.lapis.
lapis is MIT licensed. It carries Qt (LGPL-3.0), MoltenVK and Ghostty's terminal library.
